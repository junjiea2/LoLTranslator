# Contributing

Development is paused. Forks and focused pull requests are welcome; maintenance and review availability are limited.

1. Describe the problem with a short synthetic input and expected behavior.
2. Keep code changes separate from terminology/data review changes.
3. Build the solution and run `tests/LoLTranslator.DataChecks` as described in the README.
4. Include any remaining limitation, especially translation quality or hardware requirements.

Never upload raw chat logs, player identifiers, screenshots without consent, local diagnostic traces, credentials, downloaded dependency trees or model weights. Use synthetic fixtures for public bug reports. Keep provenance and candidate/review status intact when changing terminology packs.

The project captures pixels and does not require game-process injection. Please keep contributions within that scope.
